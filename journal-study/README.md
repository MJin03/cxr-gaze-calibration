# 흉부 X-ray 시선 지도학습 후속 연구

판독자의 시선을 학습에 사용하면, 같은 비율의 X-ray를 검토 대상으로 넘겼을 때 모델이 자동으로 처리한 사례의 오류가 줄어드는지 평가한다. 평가 시 모델에는 X-ray만 입력한다.

## 진행 순서

1. **기존 3분류 재실행** — EGD-CXR과 MIMIC-CXR-JPG를 연결하고, 영상만 사용하는 DenseNet-121로 정상·심부전·폐렴을 분류한다. 환자 단위 분할과 영상별 예측을 서버에 저장한다. [기존 실험 설정](../previous-study/docs/methodology.md)을 참고한다.
2. **소견별 실험** — EGD-CXR과 REFLACX에서 라벨 정의와 양성 환자 수를 확인해 소견을 고른다. 같은 환자 분할과 초기 가중치로 영상 단독, 실제 시선, 셔플 시선 조건을 비교한다.
3. **외부 평가** — VinDr-CXR에서 공통 소견을 평가한다. Emory 코호트는 접근 여부와 제공 라벨을 확인한 뒤 별도 재현 실험에 사용할 수 있다.

후속 연구의 실행 코드는 [scripts/](scripts/), 실험 설정은 [configs/](configs/)에 둔다. 원본 영상, 시선 기록, 환자 단위 파일, 체크포인트와 실행 결과는 연구 서버에 저장한다. 이전 코드와 결과는 [이전 연구](../previous-study/README.md)에서 확인할 수 있다.
